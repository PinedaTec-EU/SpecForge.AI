# US-DOC-001 · Document visual workflow states with realistic screenshots

## Metadata
- Kind: `feature`
- Category: `documentation`

## Objective
As a SpecForge maintainer, I want documentation screenshots based on a realistic workflow state so readers can understand phase status, checkpoints, model routing, and playback without relying on stale synthetic images.

Acceptance criteria:
- The workflow view shows the canonical capture -> refinement -> spec path.
- The graph remains readable enough for manual documentation capture.
- The data is fictitious but represents a plausible documentation workflow.
- The capture can be taken from the actual workflow UI rather than a custom screenshot mock.
